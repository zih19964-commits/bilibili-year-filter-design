# Release 发布目录

本目录记录从仓库初始化到 GitHub Release 的发布流程。发布时按以下顺序执行：

1. 阅读并完成 [初始化](初始化.md)，确认仓库、许可证、版本和验证环境已经准备好。
2. 阅读并完成 [提交](提交.md)，只提交已经检查过的变更。
3. 阅读并完成 [发布](发布.md)，创建版本标签并在 GitHub 上生成 Release。

本目录是发布流程文档，不是浏览器扩展的加载目录。安装扩展时请选择 starter/extension；安装用户脚本时使用 starter/tampermonkey/bilibili-year-filter.user.js。
