# 04 — UI / UX

## 1. MVP 面板

```text
┌─────────────────────────┐
│ B站年份过滤器      [启用] │
├─────────────────────────┤
│ 精确屏蔽年份             │
│ [2026] [2025] [2024]    │
│ [2023] [2022] [2021]    │
│ [2020] [2019] [...]      │
│                         │
│ 年份范围                 │
│ 隐藏 [____] 年以前       │
│                         │
│ 快捷规则                 │
│ [仅近1年] [近3年] [近5年]│
│                         │
│ 处理方式                 │
│ ● 隐藏  ○ 灰化  ○ 折叠  │
│                         │
│ □ 在卡片显示年份         │
│ 特殊内容                 │
│ □ 娱乐类                 │
│ □ 番剧 / 漫画            │
│ □ 课堂                   │
│ □ 广告                   │
├─────────────────────────┤
│ [恢复默认]               │
└─────────────────────────┘
```

## 2. 面板位置

### Userscript

右下角悬浮按钮：

```text
[📅]
```

点击展开。

### Extension

最终版优先：

- 浏览器工具栏 popup：修改全局设置；
- 页面内悬浮小按钮：快速启停。

不要只做 popup。

原因：

> 用户在浏览过程中频繁临时启停，页面内操作成本更低。

## 3. 隐藏模式

```css
.byf-hidden {
  display: none !important;
}
```

优点：

- 最符合“不想看”。

缺点：

- 网格可能在页面框架下出现空洞，需逐页面验证。

## 4. 灰化模式

```text
透明度降低 + 禁止突出显示
```

适合用户不确定某年份是否要完全屏蔽。

必须仍允许点击。

## 5. 折叠模式

卡片替换为：

```text
┌──────────────────────┐
│ 已过滤 · 2020   [展开]│
└──────────────────────┘
```

适合调试和建立信任。

## 6. 年份 Badge

调试或高级选项：

```text
┌───────────────┐
│        [2021] │
│   视频封面     │
└───────────────┘
```

Badge 只展示已经可靠解析的年份。

未知年份：

```text
[?]
```

只在 debug 模式出现。

## 7. 修改规则后的行为

规则改变：

```text
Settings change
     ↓
不重新请求 API
     ↓
读取已解析 metadata
     ↓
重新 evaluate
     ↓
重新 render
```

这是架构中必须保持的能力。

## 8. 默认设置

建议：

```text
enabled = true
excludedYears = []
minYear = null
recentYears = null
action = hide
showYearBadge = false
```

安装后默认不隐藏任何内容。

避免“插件一装上页面大量内容突然消失”。
